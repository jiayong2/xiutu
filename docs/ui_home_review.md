# 主界面布局重构：待用户审核

日期：2026-11-05。范围：只处理主界面，按用户提供参考图将“角色概况”位置替换为“天下传闻”。不重构其他页面，不修改核心逻辑、正式数值或存档格式。

## 原布局问题

- 原三等宽大面板没有突出修炼主操作，角色信息占用首页主体。
- 原九宫格入口未区分主要行动和次级功能。
- 主界面大量使用position/size及固定坐标，缺少容器尺寸分配。
- 任务区同时存在固定引导与状态摘要，完成任务后可能仍显示旧方向。
- 页标题、区域标题、正文和按钮尺寸缺少清晰统一的层级。

## 本次方案与结构

用户本次明确授权的参考布局优先于旧文档的三等宽面板+九宫格。旧设计文档未被改写。主界面局部尺寸规范：基准1920×1080；安全边距32；区域间距24；组件间距与卡片内边距16；小间距8；按钮高48；标题28/区域标题22/正文18。其余页面继续沿用现状，等待后续逐页授权。

```text
Main/Content/HomeView（MarginContainer，锚点铺满）
  VBoxContainer（间距24）
    Header（PanelContainer，高104）
      HBox：姓名境界/地点日期 + 右侧灵石
    MainContent（HBoxContainer，占剩余高度）
      CultivationCard（宽度权重3）
        标题 / 占位框 / 进度数值 / ProgressBar / 两列操作
      SideColumn（宽度权重2，间距24）
        RumorsCard（天下传闻，可滚动正文）
        CurrentTaskCard（当前任务及方向）
    PrimaryActions（PanelContainer，高度由内容决定）
      标题 / 三列Grid：地图探索、洞府经营、宗门事务
    FunctionMenu（PanelContainer，高度由内容决定）
      标题 / 六列Grid：角色、背包、功法、任务、天下、设置
    StatusMessage（单行，过长省略）
```

参考图在1920×1080下按上述统一尺寸适配；不复制参考图中装饰图标、圆角或额外画面元素。卡片使用StyleBoxFlat纯色块。姓名和境界只在顶部显示，首页不重复展示角色属性；完整属性仍由“角色”入口访问。日期保留已有小时信息。

“修炼”“突破”均转到已有修炼页面，由原页面执行操作，未添加新的结算行为。九个旧导航目的地全部保留，以主要行动3项+功能菜单6项重新分组。

天下传闻仅展示已有最新新闻，无数据时显示“暂无天下传闻”；完整新闻仍由“天下”访问。任务摘要读取现有任务状态，并处理未接取、进行中、目标达成、章节完成，不伪造任务进度。布局模块只读快照并发出导航信号。
