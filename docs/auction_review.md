# 云溪城拍卖会专项

2026-11-06。依据 [DEC-035](decisions.md#dec-035--2026-11-06通用拍卖与神识威慑)。

## 入口和当前场次

云溪城 → 地点建筑 → 云溪城拍卖会 → 入场。首期从世界第 1 日起，每 7 日举办，开放入场 3 日。当前为小型公开拍卖，入场免费，可选择匿名。已有四名 NPC 可受邀入席，参会身份只在场内有效。三件拍品使用现有回春丹、下品灵铁和精铁剑。拍卖期为入场窗口，已入场的竞拍由事件推进，跨窗口可继续。关闭界面或读档保留当前场次。

## 竞价与状态所有权

- [配置](../data/towns/auctions.json)声明地点、档期、规模、主持人、拍品、名单、性格、需求、预算、佣金与入场条件。[平衡规则](../data/balance/auction_rules.json)声明加价比例、互动、警告和行为上限。添加举办方只需注册地点和数据，界面由同一场景加载。当前公开实例只有云溪城，另一组规模、拍品及雅间数据用隔离测试验证。
- OperationService 在单个候选状态中提交进场、出价、观望、放弃、互动和下一件。首笔出价可按起拍价，后续最低加价为当前最高价的 10% 向上取整。+20% 同样向上取整。自定义填总出价。玩家和 NPC 最高价用现有钱包暂扣，被超价即退，落槌把物品交给获胜者。NPC 继续使用自身现有财富。装备由原背包服务发放唯一实例。
- 开场可先进行两轮 NPC 出价。合格 NPC 按竞价意愿、价位余量及已出价次数加权选出，仍受心理价位、当前财力和拍品轮次上限约束。玩家操作后遇到新的 NPC 报价时交回选择；无人跟价时连续完成三次询价后成交或流拍。放弃后由 NPC 继续竞拍至落槌，已经给出的有效最高价继续有效。场次号与步骤号用于拒绝旧操作，另沿用操作 ID 防重。
- 拍卖行的入场费、佣金和拍品净收入记入场所账目。云溪的 5% 佣金从成交价内划分，向下取整。购买者支付的金额等于最终出价。当前拍品归拍卖行供给，玩家寄拍和交换条件暂无入口。每场保存本期成交与有限长度日志，累计收入和 NPC 物品、财力、关系跨场持续。
- 关系使用原 NPC 的 `relations`。威胁、挑衅、威慑、身份施压以及超价和主动让出可更新玩家关系，AI 会参考对当前对手的既存关系。传音可劝退或收买，收买成功时付款。警告累计到配置上限后限制本场互动。普通 NPC 迁移规则继续由世界模拟处理。

## 识海、神魂和威慑

- 玩家读取 `player.growth.attributes.spirit_sea` 与 `player.growth.attributes.soul`，NPC 读取 `npc.attributes` 中相同键名。默认值取 [修炼配置](../data/cultivation/progression.json) 中 `mental.initial` 的 10/10。旧角色缺项时补齐；原值保持。NPC 缺项时用凡人基础值和现有境界生成，炼气每层分别加 5、3，已生成属性随第一大境突破按相同步长增长。超出第一大境保留最后一级缺省贡献，后续可按正式数据配置。
- 角色既有法修温养结算同步增长这两项，沿用原功法门槛和温养积分。上限以各自初值加上既有法修根基成长空间计算。角色页展示实际值与上限。已有四项根基继续用于原突破条件与品质；本轮没有新增神识经验、独立境界或专属功法词条。
- [统一规则](../gameplay/character/mental_attributes.gd)使用 `P=识海×0.4+神魂×0.6`、`R=识海×0.3+神魂×0.7`。成功率为 `clamp(50+1.5×(P-R)+M,5,95)`。每大境差 ±15，胆怯、强硬、动摇和防备各按 ±10 修正，合计 M 限在 ±30。
- 同一拍品同一目标只可主动威慑一次。成功使目标动摇，只有接近心理价位且需求或性格允许，或已超预算时才退场。失败增加戒备，强硬且想要拍品的 NPC 可以用同一公式反击。反击得手暂停当前拍品的主动出价和互动，观望一轮或放弃即可解除。判定使用独立的拍卖随机流。

## 竞拍流程复验

- 使用云溪城正式配置和默认起始灵石，按固定种子 1–40 复现。修复前开场两名 NPC 报价为 0/40，玩家尝试连续跟价后累计有多名 NPC 报价为 5/40；放弃或无人跟价后的询价仍需逐次触发。
- 修复后开场有两名 NPC 报价为 40/40，开场之后仍有至少两名不同 NPC 实际回价为 37/40。一次放弃落槌、无人跟价时完成三次询价、首轮询价旧档一次继续后只结算一次，均为 40/40。未结算旧档保持当前出价、退出状态和预算，后续拍品使用当前规则。两种窗口尺寸的 57 项图形检查通过。
