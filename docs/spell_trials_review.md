# 主动法术试学与界面验收

2026-11-06。用户授权见 [DEC-034](decisions.md#dec-034--2026-11-06八系法术试学与统一布局)。

## 开放内容

三个阶段的 32 个法术均通过现有装备和施法入口。新角色与旧档在加载时补授缺少的试学法术 Lv.1，原有等级与熟练度照常读入。学习与装配分开，测试时在「功法 → 主动法术」选择法术并装备，三个开放槽位沿用现行规则。

## 流程与所有权

- ContentCatalog 合并三个试学配置表到现有 spells 表。每级覆盖指定字段并继承此前字段。SpellProgression 统一提供上限、进度、词条槽和界面效果说明。
- OperationService 继续持有角色、战斗与资源。修炼先检查安全地点、寿元、灵石与等级，然后在同一候选状态扣款、调用 TimeSystem 的 `none` 模式推进世界、提交熟练度。回执和确认按钮只读结算结果。现有五个法术仍通过灵石升至 Lv.3。
- 参悟从共享测试池选出至多两个候选。生成扣除配置灵石，关闭界面保留待处理结果，选择保留或替换时都无需再次扣款。确认使用结果令牌，正式词条与技能等级配置分开。四个词条都有战斗调用。灵气弹和新增攻击法术可使用共享词条池，其他新增法术显示等级解锁槽位，尚无适用的测试池。
- BattleSystem 保留五指令、按回合选定顺序与既有胜败提交。SpellEffectResolver 统一处理攻防、治疗、状态施加、耗层、回灵、引爆和追击。BattleStatus 统一处理层数、持续时间、施加者有效攻击力快照及护盾。新增法术先读当前有效等级，施放成功后才增加熟练度。参悟使用独立随机流。
- 单挑中敌方全体和弹射只命中场上唯一有效敌人，友方单体指向施法者。敌人配置没有友方队列、常规敌方护盾或玩家侧持续伤害生产者，相应击破与驱散分支用隔离夹具验证。千羽风杀满三层风势时自动消耗；冰锥术自身的潮湿升级效果可叠加公共潮湿加层，仍受三层上限约束。
