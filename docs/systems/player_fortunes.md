# 玩家先天天赋与后天气运

2026-11-07 · PARTIAL。108 条配置已加载，逐效果依赖与统计见 [依赖清单](fortune_dependencies.md)。[数据表](../../data/fortunes/catalog.gd)保留正式 ID、名称、品质、类型、获取条件、持续机制、解除条件、互斥组及各效果的独立 ID、状态、数值、单位与适用目标。调试 F1 按相同数据列出每条效果和获取状态。

## 所有权和接口

- OperationService 在原候选状态事务中写入气运。角色创建可选零或一个已开放的先天天赋。以原有创建规则作兼容，点数制、多选及 NPC 出生分配待确认。互斥组在写入和读档时检查。
- `PlayerFortunes.record_event(actor,event,time,day_seconds,source,target)` 接收已结算的事件，只接受已连接的获取规则。入口来自已完成的突破、战斗、店铺交易、历练采药、灵植收获和炼丹。失败、试算及重复提交不会重复写入正式状态。
- `grant/remove/consume` 操作持有记录，供业务服务与隔离测试使用。新业务需从自己的已验证事务调用；资源上限变动后重新计算并钳制当前资源。当前没有已连接的一次性气运使用事件或负面解除事件。
- TimeSystem 在最近到期点拆分区间，移除到期记录后继续后续时段；当前生命、灵力和气血以新上限钳制。连续胜利类限时气运未到期时重复触发不叠加、不延长。战斗限定气运在胜利、战败或逃跑结算时撤销。
- 玩家与 NPC 属性入口可复用同一个持有记录和修正接口。现有 NPC 档案气运继续按批准档案结算；本轮没有给既有 NPC 随机分配新目录条目。

## 数值接入

- 同属性先计固定加成，再对现有基础、装备、功法、根基合计值加上固定量后的基数应用百分比。加成每次从有效记录推导。悟性目前有资质展示入口，等待正式悟性玩法消费。识海、神魂用于现有神识威慑；百分点遵守现有威慑上下限。
- 法体修为效率只修正分配给修为的灵气转化，温养和灵气池守恒沿用原逻辑。固定点余量防止短步结算改变收益。普通永久正向后天气运法体加成各封顶 30%，通用伤害加成封顶 25%。两条特殊传承按稳定 ID 优先级生效，超额传承保留持有记录。
- 战斗沿用行动顺序和既有公式。通用伤害、元素伤害及妖兽伤害接在普攻与直接法术伤害入口；独立状态、引爆和反震仍沿用各自规则。气运可参与法术消耗、闪避、生命阈值防御、承伤、回合恢复和已接入的限次触发。当前每轮一条玩家指令，首次施法减耗和首次木系直接治疗按该约束结算。
- 按 DEC-032，只有筑基走概率判定。已连接的通用概率修正只对筑基生效，后续已开放的大境界仍确定成功。厚积薄发与现有修为封顶规则冲突，逆境求道缺少失败恢复判定，两者保留待审。
- 普通商店报价和结算共用修正价格，买入向上取整、卖出向下取整；拍卖沿用原规则。炼丹计数和耗时接入现有配方。当前配方确定成功，成功率、品质升级和辅材返还待批准对应机制。
- 草药额外收获使用现有历练随机流；种植速度在播种时固定成熟时间。没有气运加成时保留原随机消耗。养成、贸易、宗门、NPC、事件奖励各自保留原业务所有权。
