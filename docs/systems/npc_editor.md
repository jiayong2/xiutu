# NPC 初始定义编辑器

2026-11-07，SYS-NPC-EDITOR，PARTIAL。依赖 ContentCatalog、NPC 月度模拟、人物档案、统一属性计算和版本 1 存档。

## 打开与使用

在 Godot 的「项目设置 → 插件」启用「仙途 NPC 编辑器」，点击编辑器顶部的「NPC」。左侧可以搜索、新建或复制人物。编辑后使用底部的「保存定义」。如需放弃草稿，使用「撤销未保存修改」。磁盘定义变动后先重新载入再继续。工具在游戏内没有入口。

装备页用同一个选择器浏览各部位，实例可保留在持有列表中，装备后可调温养。先在修炼页设置战斗底值，就能查看装备、功法、根基和已接通的气运属性贡献。右侧差值与当前人物打开或最近保存时的属性比较，悬停查看来源。

左侧默认显示全部 NPC，可同时按姓名和天资评级筛选。基础栏可点选性别，从现有人物档案选择性格，并用项目文件选择器指定头像和立绘。修炼栏提供评级选项。「随机生成人物」生成一份未保存草稿，随机选择性别、灵根、评级、性格、法修层级和现有 NPC 所在地点。战斗底值使用现有出生配置，年龄使用现有 NPC 默认值。草稿可调整，手动保存后才进入定义表。

基础栏的「初始所在地」读取人物定义中的地点 ID，显示地图名称并包含已配置的宗门驻地。名册悬停也显示该地点。天资评级固定为天骄、人杰、精英、良才、普通、凡人，未设置或不在列表中的评级显示普通。职位单独显示在身份栏。

修炼页的「法修境界」显示实际数值，「在游戏中公开法修境界」控制游戏中的披露。右侧「游戏显示」和人物交互共用显示规则。实际境界和公开开关分别校验并保存。未公开的修士显示「境界未知」，凡人显示「凡人」。

气运页默认显示初始配置。用「从存档读取气运到草稿」选择游戏存档，可读取当前选中人物的永久运行气运，含原档案气运。读取只更新草稿，需手动保存才写入初始定义。新游戏每次重读磁盘定义。

标题栏可「选择存档」，名册随即读取该档人物及其运行数据。存档中的原型人物与编辑版人物都可修改编辑器各页的字段。保存过的原型人物在该存档采用编辑版人物结构，保留运行中未开放编辑的财富等状态。根基写入档案和运行属性，装备、物品、技能和关系沿用已有校验。存档里没有的人物直接导入。原文件名保留，存档同目录的 `npc_backups` 最多保存 5 个轮换槽。

切换人物时自动暂存草稿。改过的人物和标题栏「保存」按钮会显示星号，标题栏同时显示未保存人数。点「保存」后整批校验、备份一次并原位更新。失败会保留原档和草稿，修改后可重试。若磁盘文件在选中后被其他操作改变，写入会停止。草稿只保留在编辑器会话中。

存档模式把该档玩家与 NPC 一并纳入关系对象校验，保留拍卖等玩法产生的玩家好感记录。子进程的保存结果采用 ASCII 兼容编码传输，编辑器按原中文显示。

开发构建支持在现有存档中测试人物。先在编辑器保存定义，游戏中载入目标存档，按 F1 选择 NPC。新增人物用「导入到当前档」，原型人物用「同步气运」，编辑版人物用「同步装备与气运」。原型人物同步保留原装配。编辑版同步更新穿戴、温养、气运与战斗底值，保留年龄、位置、境界、修为和其他持有装备。导入及同步均提交当前会话，通过游戏的保存功能可写入新存档版本。

F1 顶部直接列出已保存的人物、初始所在地和气运条数。「重新读取 NPC 名单」从磁盘刷新并保留选中人物。在主菜单也可查看名单，导入和同步需要先进入游戏或读档。

## 数据与运行入口

- 原型定义位于 `data/world/prototype.json`。工具按稳定 NPC ID 读取和保存 `data/world/npc_overrides.json`。文件首次保存时创建，保存经临时文件重读校验后替换。新增、复制和随机草稿采用随机生成的稳定 ID。
- 新游戏初始化使用合并后的名册。编辑版人物的档案、装备、技能、气运及初始关系进入新游戏状态。现有存档继续使用原有名册和运行状态，已有编辑版人物的档案随档保留。未接触的原型 NPC 保留旧初始化和补录规则。
- 装备定义和实例分开。穿戴校验与玩家装备共用，越境折扣和温养使用 EquipmentValues。装备实例、堆叠物品与拍卖沿用已有键形状。功法与法术分别保存学习等级和装配顺序。支持已有分级法术的熟练度格式。
- 气运通过真实库 ID 选取，支持多项永久先天气运，沿用既有授予记录、唯一性和互斥检查。初始来源标记为 NPC 初始配置，不发布获得事件。历史档案气运保留原条目。临时、战斗限定气运因缺少 NPC 生命周期而拒绝保存。见 [DEC-043](../decisions.md#dec-043--2026-11-07npc-多项先天气运)。
- 预览和运行档案共同调用 `CharacterSystem.npc_stats`。有最终属性覆盖时，档案保存启用项、覆盖值和保存时的计算原值。运行重新计算底值和贡献，并把覆盖差额单列。
- 年龄按 NPC 初始年龄和世界月度累计。法修、根基和交谈使用实际字段。宗门、性格、天资评级和体修境界属于可编辑档案信息。人物关系保存现有方向的好感分和档案描述。

## 已核对的缺口

当前战斗的敌方入口接受怪物 ID。NPC 法术槽尚无实际战斗决策消费者。独立法宝能力、通用 NPC 行为目标与活动、NPC 宗门成员、关系配对和双向约束缺少运行契约。功法没有逐级熟练度记录。气运非属性效果继续遵循各现有依赖的接入范围。相关界面标明可用范围，后续玩法需独立确认。

## 验收路径

`tests/npc_editor_tests.gd` 通过 Godot 4.5 Mono 无头验证，覆盖编辑面板实例化、真实武器选择器、新建测试定义、写入替换和重读、资源与实例保留、既有档恢复、新档初始化、运行档恢复、共享属性计算、卸下、移除气运和非法引用。图形编辑器布局尚待实机检查。
