# 装备 V1 部分交付

2026-11-07 · PARTIAL

角色 → 装备 → 领取炼气装备。新档、旧档均可一次性领取青锋剑、清心冠、青木法衣、雷纹护腕、聚灵腰带、疾风灵靴、清心坠、回春戒。物品进入背包，玩家可自行穿戴，旧武器保留。领取与装卸通过 OperationService 提交，玩家存档保存实例及槽位。

## 计算

普通装备沿用统一角色属性计算。装备生命写 hp，独立于 blood。识海和神魂加值进入现有神识威慑的有效属性，保持成长上限规则。镇魂暂按相对倍率放大威慑成功率，沿用原上下限。

新增 V1 装备使用推荐境界。暂定低于最低推荐境界时，正向基础属性和器蕴乘 0.5；速度惩罚保留。旧模板继续使用原装备门槛。温养按 0/3/6/9/12/15% 计算，与越阶系数相乘后统一四舍五入。只提升正向普通基础值；识海、神魂及器蕴不随温养变化。角色装备详情的温养按钮通过 OperationService 每次为选中 V1 普通装备提升一层，达到 5 层后禁用。当前无灵石、材料或时间消耗，穿戴与否均可温养。旧模板无温养字段，不能温养。

锋锐、聚灵在属性汇总生效。燃灵在灼烧跳伤生效。破盾在护盾吸收时生效。玄龟护体在护盾后最终扣血阶段生效。暴击和闪避沿用原判定及上限。破甲沿用防御计算，厚土使用现有护盾及容量上限，回春接入战斗治疗结算，五行增幅接入对应五系法术。清心与青木护体尚未接入，悬停明确标记。回春尚未覆盖所有物品及非战斗恢复入口。

## 界面与验证

背包、角色装备和商店行共用 equipment_hover.gd。节点为 PanelContainer → ScrollContainer → VBoxContainer，内含标题 HBoxContainer、42×42 Panel 图标、RichTextLabel 分区及 ProgressBar。品质、五行、基础属性语义色集中维护。无器蕴时省略区块。角色装备详情使用同一分区渲染数据，详情可独立滚动，装卸和温养按钮固定在下方。角色信息页的三栏内容可整体纵向滚动。

8 件法宝已有独立配置与唯一神通 ID，法宝槽位、持续威能、神通结算、祭炼和说明框仍待接入。保持现有战斗指令和存档格式。
