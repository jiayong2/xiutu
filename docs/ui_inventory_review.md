## 分类和数据规则
全部、丹药、功法、法术、装备、材料、任务物品。
原消耗品和丹药显示“丹药”；秘籍按use_effect.learn目标分功法/法术；equipment实例归装备；quest.required_item指向物品显示任务物品；灵草、种子等归材料。映射集中于原背包服务的一个只读方法，不改商店既有分类。
普通物品原状态仍为总数量，只在显示层按正式stack_limit拆组；现有上限99，205显示99/99/7。显示键为物品ID+组序号，装备使用独立实例ID；不按名称识别。不新增持久堆叠字段。
材料及任务物品只展示详情；没有通用使用按钮。装备仅使用已定义equipment接口，未新增法宝功能。
选择与筛选不执行操作，分类隐藏当前项会清空选择；仍可见则保留。数量耗尽移除物品格。原有已学限制、恢复已满、每日服丹及境界条件通过真实事务验证。
