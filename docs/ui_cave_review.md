- 修炼室：33/34/33，年月天SpinBox及加减，六个快捷时长，开始闭关和只读收益/年龄预览；保留晋升。
- 灵田：42/33/25，2列卡片及独立滚动、选择详情、种子库存、单一播种/收获按钮。按实际四块显示，不将示意图两块变成数据修改。
- 炼丹房：60/40，丹炉矩形、已有两丹方和材料/时间/消耗，继续真实炼制；不会按旧示意图禁用已有能力。

## 规则边界
用户本轮明确要求年月天自由设置，故增加洞府专用retreat，取消其固定日数限制；原practice命令保留旧行为。不将示意图的历法当依据：读取现有TimeSystem月720小时和rules年360日/日24小时。没有新增999年等玩法上限；SpinBox最大显示值10000仅滚动范围，allow_greater允许直接输入更大数字，不作为规则上限。
现有寿元规则是已到寿元不能开始操作，时间推进后按真实年龄进入终局；原系统不阻止一次操作跨过寿元。本轮保留该行为，预览会说明闭关后达到寿元，不自创寿元截断或收益截断。
原公式只在闭关开始读取环境、功法和阵法；长期闭关跨月的阵法维护仍由TimeSystem结算，不重算原收益公式。单日取整与多日一次取整结果可能不同，保持原逻辑。
原修为允许超过当前突破需求，预览如实显示，不自动晋升或人为封顶。
种植不推进时间，收获按现有配置，不虚构品质或数量；真实炼丹保留。
英文game_design/content_v0_1/combat_balance缺失仍按项目中文原文与批准记录；当前无Git仓库，未提交。

## 未改系统问题与下一步
超长闭关仍由既有TimeSystem逐月模拟，极长输入可能耗时；未引入分帧模拟或新时长规则。月份/年份按当前实现，未改现实历法。地点内部旧“修炼室”入口仍指向原修炼页，主界面洞府入口进入新统一页面；未改任务、地图或其他页面。
建议审核四页视觉；不自行推进后续玩法或其他UI。
