三个场景均可直接在Godot编辑器打开，布局节点已保存，不依赖启动时创建。调整容器Stretch Ratio、间距、内边距和锚点可改变排列。根AGENTS.md模板范围按本轮明确授权更新，其他界面模板不扩展。

## 交互与保护

点击地图节点仅更新选择，右侧显示地点简介、开放/锁定状态与移动耗时。可进入状态通过原OperationService旅行请求在隔离副本上查询，实际进入再提交正式travel操作。副本查询不修改真实状态或随机流。路线仅作视觉连接，不新增邻接限制或路费。

进入地点后调用原travel处理地点、时间及云溪城解锁。建筑打开现有商店、修炼/洞府页面或提交现有inn/explore/challenge请求。空白区域禁用，不伪造功能。附近人物读取当前NPC位置与存活状态；点击只打开对话页，不立即推进任务。

点击“交谈”调用原talk接口，显示原返回文本并触发原任务事件。“任务”沿用原任务日志，仅秦守山有对应入口；结束/返回回到地点场景。场景右侧“其他功能”位置用于返回主界面，不新增未定义玩法；“可用活动”位置显示当前真正可执行的休息/修炼/探索入口。

未修改地图节点ID、NPC、任务、时间、战斗、静态数值或存档系统。地点场景复用既有状态，UI页面本身不写玩家位置和日期。原英文设计文件等缺失问题沿用历史记录，本轮未据此新增规则。
