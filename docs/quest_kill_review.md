# 清剿山狼验收记录

2026-11-08。按用户提供的《妖兽击杀类测试任务：清剿山狼（完整实施版 V2.0）》实施。

青岚镇公告栏新增一项测试委托。现有对应妖兽的正式名称是灰牙野狼，ID 为 `monster_gray_wolf`。青石山道的遭遇表不包含它，青岚山外围直接探索可以遇到它，因此任务线索指向外围直接探索。未调整地图、遭遇表或妖兽数据。

任务沿用 `KILL_ENEMY`。`OperationService._finish_battle` 在有效胜利候选事务内发布怪物 ID、数量及战斗 ID，`QuestSystem.notify` 核对当前胜利战斗并去重。第三次击杀进入待交付。公告栏现有主按钮提交当前轮次，奖励和完成记录同时提交。领奖后经过 TimeSystem 计量的三个完整游戏日才开放下一轮。
