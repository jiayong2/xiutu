## 真实数据与行为
顶部从player及唯一hours读取姓名、境界、地点、灵石、世界时间。左上只读取tracked_quest_id对应的有效进行中任务，目标与计数来自QuestSystem；无追踪显示空状态，不再自动挑选其他任务。点击定位任务详情。
建筑从现有商店配置、客栈与原地点交互逻辑映射：青岚两商店+客栈，云溪药阁+客栈+已有宗门入口，洞府修炼室/总览/灵田/炼丹，野外探索/调查/狼首挑战。商人不在地点或死亡禁用；没有新增正式建筑或商品。洞府标签定向映射现有Overview/Fields/Alchemy。
NPC仅显示alive且location等于玩家地点者；现有配置没有activity或role时显示“可交谈”，没有编造巡查、休息等活动。原对话接口仍校验可交互状态。
世界消息读取state.news倒序及真实操作反馈，近期操作缓存上限50，不写存档，不创建世界模拟或虚假事件；全文悬停、条目最多两行，列表内部滚动。天下仍有完整NPC和世界信息。
修炼打开原修炼流程；突破提交promote，失败显示真实原因；野外原有禁止修炼仍保留。地图旅行通过原travel；商店、NPC、洞府、宗门返回地点场景时现在显示同一地点主界面，真实位置未改。
字体继续使用用户提供思源黑体。

## 数据缺口与边界
当前没有地点灵气浓度正式字段；显示“灵气：未定义”，效率从原系统读取，不为参考图添加正式倍率。初始城镇效率1.10包含原吐纳诀10%，不能误写成1.0；洞府1.21还包含原洞府环境，未重复叠加。
本轮只读复用已有行为，未实现NPC巡查/休息等新AI。没有正式背景美术。
英文game_design.md、content_v0_1.md及combat_balance.md历史缺失仍在，读取现有中文设计来源与当前技术契约。无Git仓库，未提交。
