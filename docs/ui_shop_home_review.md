## 复用
沿用现有ShopSystem/OperationService报价与交易、背包、货币、随机与TimeSystem；NPC仍通过原talk及npc_option；页面只发请求。使用原灰蓝/青绿Control主题风格与全局思源黑体。
购买、出售和观察结果在主界面已有recent_messages会话缓存中追加，最多50条；回到店内可见。交易消息包含物品名称/数量/成功或失败原因，不再只有操作成功。世界消息仍读取原state.news。无第二套消息存档或模拟系统。
店内默认无商品列表、无对话、无物品详情；允许默认选择掌柜，只展示简要身份。

## 真实内容边界
原杂货铺掌柜为柳青禾；不替换成演示周掌柜。NPC必须存活、位于店铺所在城镇，且为配置关联掌柜，或已有npc.shop_id明确指向该店铺，才在店内显示；不会将城镇所有NPC当顾客。现有模型无顾客室内位置数据，当前通常只有1位掌柜，没有新增NPC或室内AI。
店铺介绍按现有库存类型配置；不填写示例中的错误商品或虚假顾客活动。原补货为每月结算，公告说明现有月度规则；不实施“每日辰时补货”。不补货店铺明确说明不自动补充。营业状态按原交易中掌柜存活、位置及玩家位置条件推导，无新营业时间系统。
UI店铺上下文为会话导航，不改变player.location或新增存档字段；回城保留实际地点。没有独立室内地图、寻路、讨价还价、装修或新经济规则。
