# 统一NPC交互 V1.0 验收
日期：2026-11-05。结论：PASS（本轮弹窗与已有功能接入），等待视觉审核。

## 文件与实现
新增ui/npc/npc_interaction.tscn及npc_interaction.gd：一套1100×550居中弹窗、轻遮罩、关闭按钮，无独立标题；左姓名/立绘矩形/关系，中境界身份，右固定两列六行12按钮，底部92px内部滚动反馈。尺寸不足时统一缩放。交谈、任务在右侧局部子面板，结束回12按钮。
新增world/npc_interaction.gd：轻量只读适配器evaluate/presentation，统一判断当前数据是否允许已有交谈/任务/交易/查看，不新建角色、关系或对话数据库。
修改ui/main/main.gd：open_npc_interaction统一入口，城镇/任务/店铺/原世界NPC信号/宗门接同一弹窗；旧NPC页面导航被重定向为弹窗，旧全屏场景保留历史文件但正式路由不再使用。原背景页面实例保留，弹窗内操作不重建背景；关闭只重新绑定真实变化的值，并恢复滚动位置。
修改ui/sect/sect_page.gd：实际NPC行与交谈入口接统一弹窗；没有NPC时仍空状态，不新增宗门NPC。
修改ui/shop/shop_home.gd：刷新时保留仍有效的人物选择。
新增tests/npc_interaction_preview.gd；更新tests/home_layout_preview.gd、shop_home_preview.gd的旧全屏对话断言为弹窗及层级返回断言，业务保护断言保留。

## 已接入与占位
真实交谈：原talk，原文本在弹窗反馈显示；专属剧情/任务选项来自QuestSystem.dialogue_options并请求原npc_option。保留接受、进展、报告、交付及防重复逻辑，普通交谈不代替专属选项。
真实交易：根据shops.npc_id匹配当前人物及地点，显式点击后实例化原shop_page作为二级交易界面；钱、背包、库存由原服务结算，返回仍保留人物弹窗及背景。任务材料出售继续原确认与校验，不绕过保护。
任务：局部显示该NPC现阶段真实选项；无任务反馈“目前没有可委托你的事情”。查看只使用玩家已知信息。
打听/赠礼/请教/论道/切磋/邀请/拜师/其他为可点击占位，统一明确“该互动功能尚未开放”，不伪装NPC的真实决定，不执行任何资源或关系操作。
全部12按钮不因身份、位置或能力而禁用/隐藏。已有功能统一检查NPC存在、存活、同地点、当前战斗及商店关联等真实条件；商人无货物、远处人物、已故人物分别反馈具体原因。没有性格、忙碌日程或关系阈值规则时，不编造对应拒绝。
当前无完整已知境界系统，只有NPC明确realm_known=true时显示其境界；缺少该标记显示境界未知。relations中没有玩家记录时显示“关系：未记录”，不将空记录冒充陌生0分或相识25分。未新增认识/送礼成长或师徒规则；没有存档字段迁移。

## 交互与状态
关闭按钮只关闭弹窗。ESC先关闭二级交易，或返回局部对话的12按钮，再关闭人物弹窗；不打开全屏对话、不改变原page或player.location。城镇/店铺/宗门背景节点不重新实例化。现有无NPC的地点无需造测试NPC进入正式配置。
